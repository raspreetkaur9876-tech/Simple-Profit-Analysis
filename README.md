# Simple Profit Analysis

## Project Overview
This project analyzes total profit across different product categories using Microsoft Excel and the Sample Superstore dataset.

## Objective
To compare the total profit of Furniture, Office Supplies, and Technology.

## Tools Used
- Microsoft Excel
- PivotTable
- Column Chart

## Analysis
- Furniture has the lowest total profit.
- Office Supplies generates higher profit than Furniture.
- Technology has the highest total profit.

## Key Learning
This project helped me understand how to summarize data using PivotTables and visualize profit comparisons using charts.

## Conclusion
Technology is the most profitable category in this dataset, while Furniture generates the lowest total profit.
